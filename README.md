# 小词窗 1.5.6

Windows 本地单词拼写工具：小窗口显示中文释义和遮词例句，输入正确后自动下一题。无需账号或后台服务，日常练习不联网。

## 使用

1. 双击 `小词窗-Setup-x64-v1.5.6.exe`，按中文向导安装，再从开始菜单打开“小词窗”。**升级前先从旧版托盘选择“退出”。** 也可完整解压便携包 `小词窗-Windows-x64-v1.5.6.zip`，运行其中的 `Vcrmb.exe`，并保留同目录 DLL 和配置文件。
2. 窗口默认在主屏右下角、任务栏上方；拖动中文释义移动。在练习窗中按 **Ctrl+,** 打开设置，设置章节、每组词数和组号，也可调整置顶、锁定位置、宽度和字号；托盘也提供设置入口。
3. 根据中文和例句填写**词条原形**。例句中的原形、英美变体和已识别的屈折变化统一遮为 `______`，空白长度不透露字母数。短语保留空格，连字符词保留连字符。

适用 Windows 10 1607+ / Windows 11 x64，需 .NET Framework 4.8 或兼容的 4.8 系列运行时。本次在 Windows 10 22H2 x64 上编译和启动过；Windows 11 尚未实机验证。使用发行包不需要安装 Python、.NET SDK 或数据库服务器。

安装包默认安装到 `%LOCALAPPDATA%\Programs\Vcrmb`，只为当前用户安装，无需管理员权限。自动创建开始菜单入口，桌面快捷方式可选；不设置开机启动。缺少 .NET Framework 4.8 时会提示所需运行时，安装器不自动下载或安装系统组件。

便携版和安装版默认共用 `%LOCALAPPDATA%\Vcrmb` 中的学习记录，直接安装即可续练。后续安装包可覆盖升级；程序运行时会阻止升级和卸载，先从托盘退出。可在 Windows“应用和功能”中卸载“小词窗”，**卸载保留学习记录、设置与备份**。安装包没有代码签名证书，Windows 可能提示未知发布者；旁边的 `.sha256` 文件用于核对下载或复制后的完整性。

| 操作 | 按键 / 入口 |
|---|---|
| 全局显示 / 隐藏 | 默认 `Ctrl+Alt+Shift+W`，可自定义 |
| 隐藏练习窗 | 默认 `Esc`，可自定义 |
| 提示 | 默认 `F1`，可自定义；一次显示完整答案 |
| 跳过 / 下一组 | 默认 `F2`，可自定义；组内跳过当前词，完成页进入下一组 |
| 重练当前组 | 默认 `F3`，可自定义；从本组第一个词重新开始，保留累计次数 |
| 提交输入 | `Enter`；答错立即展开完整答案，正确完整拼写仍自动通过 |
| 修改输入 | 直接编辑，或 `Ctrl+A` 后重输 |
| 设置 | `Ctrl+,`，或托盘“设置” |
| 学习记录 | 设置 → 学习记录，或 `Ctrl+S` |
| 完全退出 | 设置页左下角“退出程序”，或托盘“退出” |

设置统一分为“练习、外观、快捷键、学习记录”四个页签。备份、恢复在“学习记录”页。悬浮窗没有 Logo、工具栏或操作按钮，提示、跳过、重练、设置和隐藏均通过快捷键操作。提示直接显示完整答案。

**修改快捷键：Ctrl+, → 快捷键。** 点击录入框，直接按下新组合，再按 Tab 或点其他位置，最后点“保存设置”。支持全局显隐、窗口隐藏、提示、跳过和重练当前组，以及恢复默认。显隐键需要修饰键；其余可用 F1–F11、Esc 或带 Ctrl/Alt 的组合。相互重复、文字编辑和系统保留的常用组合会被拒绝。Ctrl+, 固定用于打开设置。

旧设置尚无“重练当前组”按键时，优先补为 F3；如果 F3 已被其他操作使用，则在 F4–F11 中选择第一个空闲键，原有快捷键保留。实际按键可在设置页查看。

录入框聚焦时暂时释放全局显隐键，离开后恢复，保存后才应用新组合。冲突时会显示原因并尽量保留原组合。只有全局显隐在其他软件中也生效；托盘绿色 W 图标始终提供显示和设置入口。再次启动相同数据目录的程序会唤回现有实例。

正常模式不显示任务栏按钮；窗口靠近任务栏放置，并非嵌入任务栏。全局隐藏会关闭设置及本程序的文件对话框，未保存的设置取消。Esc 在设置页关闭该页，在快捷键录入框内则作为待录入键处理。

## 分组练习与跳转

按 **Ctrl+, → 练习** 打开配置：

1. 选择学习章节。“全部章节”按全书词序分组，单个章节只在本章范围内分组。
2. 设置“每组练习词数”，默认 **20**，支持 **1–3674** 的整数。每组 20 词时，第 1 组为第 1–20 词、第 2 组为第 21–40 词；全书共 184 组，最后一组 14 词。这是自定义练习分组，不使用原书小组编号。
3. 在“跳转到哪一组”选择目标组，选项显示词序范围和实际词数。“保存设置”继续该组原有进度；“跳转并从头练习该组”重置该组本轮进度和适用的未完成输入。**累计正确次数、错误次数不清空。**

普通模式一组内每词处理一次，包含以前学过的词。答对或跳过推进一个词；错误、提示、编辑和隐藏不占额外名额。答对仍自动切换组内下一词，整组完成后停在完成页，按跳过快捷键（默认 F2）继续下一组。最后一组完成后按该键回到第 1 组。曾完成的组会开启新一轮，中途离开的组则续练。

练习窗获得焦点时，按重练快捷键（默认 **F3**）立即从当前组第一个词开始。练习中和完成页都可重练；清空本组本轮进度、输入及提示，保留累计正确/错误次数和其他组的未完成输入。也可在设置中选择“跳转并从头练习该组”。

章节、每组数量和组号分别保留分组进度。修改章节或数量时选择框先回到第 1 组，可再指定其他组；保存才生效。重启、隐藏和备份恢复保留进度与输入。返回有草稿的组时先继续草稿，其余按词库顺序进行。

1.5.2 已移除设置页的“只练习所选组内的到期复习词”和“复习间隔”。统一练习所选组的全部词，不按到期时间筛选；旧版曾启用该筛选时，启动和恢复备份后都会自动回到普通分组练习。累计次数和普通分组进度保留，数据表结构与旧版备份继续兼容。

## 图标与悬浮窗外观

“窗口 + W”图标用于 EXE 文件、系统托盘和设置窗口，悬浮窗不显示图标。源码为 `assets/logo.svg`，构建时导出 16–256 像素的 9 尺寸 ICO；PNG 和 ICO 均嵌入程序，不需额外图标文件。

**Ctrl+, → 外观 → 悬浮窗背景：**

- **磨砂玻璃**（默认）：模糊透出后方窗口，默认浓度 65%，可调至 20%–90%。
- **全透明**：去掉可见背景，只保留释义、例句和输入文字。
- **纯色**：使用清晰、稳定的实色背景。
- 勾选“深色外观”会使用浅色文字，适合深色桌面；浅色背景通常保持默认配色。保存设置后生效。

只有背景透明，文字和输入光标保持原有清晰度。合成接口不受支持或系统处于高对比度时采用实色背景。效果由本程序调用系统合成实现，不需要安装 TranslucentTB，也不会修改系统任务栏。

**Ctrl+, → 外观 → 光标闪动：** 默认关闭，悬浮窗输入框获得焦点时显示常亮光标；勾选后跟随 Windows 的光标闪烁设置。保存后立即生效，重启及备份恢复保留选择；旧版没有该配置时也默认关闭。只影响悬浮窗输入框，不修改系统设置或其他软件。选中文字、切出窗口或完成本题后收起光标。

悬浮窗从上到下为中文释义、遮词例句、无边框输入区。主动提示或回车提交错误时，完整答案以绿色文字直接接在中文释义后面，空间不足时自然换行；输入框下方不再增加答案行。长释义可滚动，显示提示时自动滚到末尾让答案可见。中文释义兼作拖动区，锁定位置后不可移动。

默认基础字号由 14 调大到 **16**：释义及提示为 17，例句为 16，输入文字为 18。可在 **Ctrl+, → 练习 → 字号** 调整。已有设置中的字号继续保留；旧版已保存为 14 时，可在该处改为 16。窗口高度随内容和字号调整。

输入区在英文例句下方，**没有白底、方框和常驻说明**；点击该区域即可输入。空输入不会显示催促文字。回车提交错误时显示红色 × 和细线，并在释义后展示全部允许答案；修改后错误标记消失，答案继续保留。答对显示短暂 ✓ 后自动下一题，原题答案随之收起。短答案是其他允许拼写的前缀时，按 Enter 确认。必要的保存/运行故障仍在输入区下方显示。

1.4 修复了提示答案只露出几个笔画的问题：展开或收起答案后，圆角裁剪跟随实际窗口大小更新，调整宽度或字号时也同步处理。

## 拼写和提示

- 忽略首尾空白、连续空格和大小写；全角英文会归一化，只接受词库列明的答案。
- 输入正确仍自动切换下一题；手动按 Enter 代表提交，答错立即展开全部允许答案。输入过程中不报错；错误提交后留在当前题，保留输入以便修改重试。
- `program / programme`、`lab / laboratory` 等前缀变体，较短答案需 Enter 确认，也可继续输入完整长答案。
- “提示”直接显示全部允许拼写，不填入输入框，也不自动完成本题。提示后仍需自己输入。
- 练习范围由章节、每组词数和组号决定。本轮已处理词不会重复插入，需要再练时按重练快捷键（默认 F3），或在设置中选择“跳转并从头练习该组”。
- 切换章节或组号保留未完成输入、提示和错误状态。隐藏或中断不计为答错，也不自动跳过。

## 学习记录

只按词条累计，表格显示 **单词、正确次数、错误次数、正确率**，可按英文或中文搜索，点击列标题排序。鼠标停在单词上可查看释义，区分同形词条。

- **正确次数**：每次成功拼写完成加 1；用过提示、粘贴或输错后重试的答对，也加 1。
- **错误次数**：每次按 Enter 明确提交错误加 1，当题未完成也立即保存。空输入不计错。
- **正确率**：正确次数 ÷（正确次数 + 错误次数）。例如先错一次再答对，显示正确 1、错误 1、正确率 50.0%。
- 编辑输入、提示、跳过、隐藏或切换章节不增加次数。没有作答的词条不显示记录。

不再按日期保存学习流水，也不统计学习时长、每日/最近七天记录、辅助答对或熟练目标。分组进度与当前未完成输入单独保存，用于继续练习，不构成按日期划分的学习历史。旧版复习数据保留兼容，但不参与新版的分组筛选。

## 固定词库

程序固定内置 **3674 个来源词条、22 章**，词库已嵌入 `Vcrmb.Core.dll`。没有导入、更新或编辑词库的入口；程序不读取安装目录或用户目录中的外部 `vocabulary.json`，备份恢复也不能改变词库。

来源为参考会话指向的 [hefengxian/my-ielts](https://github.com/hefengxian/my-ielts)，固定提交 `5cef573933663c4673c6e0093f1df04e68018b1a`。保持来源 ID 和允许答案数组。51 个词条有校对记录，其中 40 条采用自拟替代例句（含原先缺失的 4 条），其余涉及不规则词形或释义清理；原例句、原释义和来源信息保留在内嵌数据中，改动原因在源码 `data/corrections.json` 中。

已自动检查全部例句遮词和释义答案泄漏，尚未逐句人工校对全书的语义与语法。来源 README 禁止商业用途，未发现单独的标准开源 LICENSE；本项目用于本地个人学习，词库内容不因本仓库公开而获得额外许可。详见 `THIRD-PARTY-NOTICES.txt`。

## 升级、备份和恢复

**1.0 / 1.1 升级到 1.5：** 首次打开旧学习库时，先在数据目录生成 `升级前-*.sqlite`，再将历史记录汇总成每个词条的累计次数。已有正确次数、错误次数（含未完成题目中的错误）、自定义快捷键、未完成输入和复习安排都会保留。重复启动不会重复累加。

升级前备份保留旧结构以便回退；当前学习库删除旧日期、事件及活动时长表。**转换后的库不能用旧版程序打开；回退需要使用升级前备份。** 如旧版曾导入增加了新 ID 的词库，升级会拒绝不兼容的记录，原数据不会被覆盖。

正式数据位于 `%LOCALAPPDATA%\Vcrmb`，界面不再提供打开数据目录按钮：

- `learning.sqlite`：累计次数、设置、当前未完成输入和复习安排；运行时可能同时存在 `-wal`、`-shm`。
- `升级前-*.sqlite` / `恢复前-*.sqlite`：升级或恢复前自动保留的原数据。
- `error.log`：异常时写入的本地诊断信息。

在 **设置 → 学习记录 → 备份学习记录** 生成单个 SQLite 备份，包含记录、设置和未完成输入。请使用此功能，不要在运行时只复制主数据库而忽略 WAL。迁移电脑时带上完整程序包和备份即可。

1.2 / 1.3 / 1.4 升级到 1.5 不改变数据表结构；新增分组进度随学习备份保存。已有快捷键和外观继续使用。旧设置缺少组号时，优先定位到未完成词所在组，否则选择首个未学词所在组，默认每组 20 词。

恢复支持 1.0 / 1.1 / 1.2 / 1.3 / 1.4 / 1.5 的学习备份。校验标识、结构、完整性和词条 ID 后再替换，旧版备份会先在临时副本中转换；恢复前另存当前数据。恢复也会替换设置，完成后设置窗口关闭，避免随后保存旧表单覆盖恢复结果。

## 构建与验证

在 Windows PowerShell 5.1+ / PowerShell 7 的项目根目录执行：

```powershell
.\build.ps1 -Test -Installer
```

首次构建下载并校验 `dependencies.json` 中固定 SHA-256 的三个包：.NET 4.8 参考程序集、System.Data.SQLite 2.0.4 和 SQLite 3.53.4 x64。使用系统 C# 编译器，无需全局 SDK；有效缓存存在时不访问网络。

`-Installer` 同时生成便携 ZIP 和 EXE 安装包。额外按固定 SHA-256 和 Authenticode 发布者校验 Inno Setup 7.1.0 x64，并以官方 portable 模式放入 `.tools`，不安装全局编译工具。只需便携 ZIP 时用 `-Package`，仅编译时不加打包开关。安装脚本位于 `installer/Vcrmb.iss`，输出采用运行文件白名单和逐文件 SHA-256 校验；源代码、测试程序、构建工具与个人学习记录不会被装入安装包。

安装生命周期回归使用 `tests/Installer/Smoke.ps1 -InstallerPath "安装包完整路径" -PackageDirectory "对应发行目录"`。它只允许在没有已安装“小词窗”、同名快捷方式或运行实例的用户账户下执行，测试后移除临时安装项，保留 `artifacts/installer-smoke` 中的验证数据和日志。安装验证报告为 `reports/installer-validation-2026-09-30.md`；机器可读结果为 `artifacts/installer-verification.json`。

Git 只跟踪源码、测试、固定词库、SVG 图标源文件、脚本和文档。`.tools`、`build`、`artifacts`、自动生成的 ICO/PNG、SQLite 学习库、日志及编辑器缓存均由 `.gitignore` 排除，保留在本地，不提交发行二进制文件。

构建把源码 `data/vocabulary.json` 嵌入程序集。运行包不包含外部词库文件；源码中的固定快照转换器 `tools/import_vocabulary.py` 和校对文件仅用于追溯现有内置数据。测试结果为 `artifacts/test-results.json`，程序输出到 `build/小词窗`，带版本号的发行 ZIP 在 `artifacts`。

源码分为 `src/Vcrmb.Core`（固定词库、判词、复习、累计计数与迁移）和 `src/Vcrmb.Desktop`（WPF、设置、托盘与 Win32 显隐）。测试使用真实 SQLite 文件验证迁移、恢复、事务回滚和异常退出。

可用 `Vcrmb.exe --data-dir "独立数据目录"` 隔离试用。`--ui-test` 额外显示任务栏按钮并输出 `ui-state.json`，仅用于开发验证。
