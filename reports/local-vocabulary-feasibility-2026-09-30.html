1. 小窗口可行，任务栏内嵌不适合作为首版目标

“固定在任务栏”有三种不同含义：固定一个启动图标、在任务栏旁显示独立窗口、把输入框真正嵌进任务栏。你的需求需要持续展示中文、例句和输入框，第二种最适合。

形式能否满足练习实现代价与判断
任务栏旁的小窗口
首选		中文、遮词例句、输入框完整可见；可拖动、置顶和隐藏使用普通桌面窗口即可。位置可固定在任意屏幕边缘，不需要改造系统任务栏。
托盘图标 + 弹出窗口适合作为隐藏后的入口；点击或快捷键打开同一个练习窗口托盘本身只能承担入口，不适合直接放完整例句和可编辑输入框。
真正嵌入任务栏Windows 10 的旧 DeskBand 技术可研究；可用高度也偏紧需处理 Shell / COM 集成，任务栏内嵌依赖这套旧接口；Windows 11 又限制任务栏区域自定义，不宜承诺为稳定通用方案。
独立屏幕停靠栏
AppBar		可固定在屏幕边缘，但不是嵌入现有任务栏会保留一块桌面工作区，影响其他窗口的可用面积；对小型练习窗收益有限。

依据：IDeskBand、DeskBand 的 Shell / COM 实现、Windows 11 功能变更、AppBar 工作区机制。这里评价的是官方接口路线；没有把修改 Explorer 的第三方方案作为交付依赖。

2. 练习流程：减少操作，同时避免误判

环节建议行为需要明确的边界
出题只展示中文释义、可选词性、遮住目标词的英文例句和输入框遮空使用固定宽度，字母数由提示功能展示。训练词条原形；例句中即使使用复数或过去式，也遮住完整表面形式，避免误以为必须按句子填变形。
输入正确完整匹配允许答案后，短暂确认并自动进入下一词；不额外点击“下一题”只有在输入法组合结束后判定。切题必须清理旧输入事件，避免旧词尾字符进入下一题。
输入错误输入过程中不把尚未写完当作错误；按 Enter 明确提交错误答案后，显示轻量提示，留在当前题保留输入供修改；Ctrl+A 后可直接重输，不弹模态对话框，不强行清空。
逐级提示F1 依次显示字母数、首字母、更多字母；“显示答案”单独提供使用任何提示都记录；看过答案后重输记为辅助练习，并安排再次复习。
隐藏 / 恢复全局快捷键隐藏或呼出；Esc 只在练习窗内生效；托盘可恢复和退出默认组合可设为 Ctrl+Alt+W，并允许修改。冲突时明确提示注册失败，保留托盘入口。
不会 / 跳过跳过进入待复习队列；允许稍后再练记作未完成或跳过，不计为正确，也不阻塞整轮练习。

全局快捷键使用 RegisterHotKey，不需要监听所有键盘输入。该 API 会报告部分占用冲突；普通字母只由有焦点的练习输入框接收。托盘可用 NotifyIcon。

自动切题存在一个需要定稿的真实取舍。词库中有 8 组“短答案是长答案前缀”的组合，例如 program / programme、lab / laboratory。若在短答案匹配时立即切题，会打断正在输入长答案的人。建议普通词自动切题，这类歧义词在短答案处等待 Enter，长答案完整匹配时自动切题。若要求所有答案都绝对零确认，只能采用停顿延时等启发式，并接受可能提前切题；无法仅凭同一段输入确定用户是否还会继续打字。

这一条是交互方案建议，实施前应明确取舍，不把它隐藏为“已经完全解决”。答对反馈可先设为约 150–250 ms，再实测快速连续输入和按键重复；性能数字是设计目标，不是本次测试结果。

答案比较采用确定规则：处理首尾空格、全角字符和大小写；短语内部连续空格可合并。保留有意义的空格、连字符与撇号。英美拼写和缩写仅接受词条明确列出的形式，不能把相近词或同义词自动算对；需要区分大小写的词条可单独标记。

本地结构保持简单

一个桌面进程即可：窗口负责展示与输入；练习逻辑负责判词、提示和选题；数据层负责词库、答题事件和复习状态。SQLite 使用兼容目标框架的驱动并锁定版本，不需要 Java 服务、MySQL、Redis 或云端接口。微软提供 Microsoft.Data.Sqlite 这一轻量数据访问方式，具体版本在实施时核对目标框架。

默认把学习数据库放入当前用户的本地应用数据目录，程序文件与进度分开；导入新词库不得覆盖学习历史。每次提交用事务同步写入答题事件和词条状态，失败时留在当前题并提示保存失败；切题只记一次，防止重复按键重复计数。提供导出 / 导入备份，备份须使用 SQLite 正确的在线备份或关闭连接后复制，避免遗漏未合并的日志数据。

首版以 x64 解压运行包交付，不自动设置开机启动。普通用户目录内的数据读写与窗口功能按免管理员运行设计；公司终端若有应用白名单，仍需在实际电脑验证允许启动。静态词库和练习记录全在本地，运行中不需要联网；提示也不依赖在线 AI。

5. 统计应区分独立答对、提示后答对和重输

统计在独立窗口展示，通过托盘菜单打开，保持练习窗口紧凑。记录每次“出题”、明确的错误提交、提示、答案揭示、跳过、最终结果和有效练习时间；不把每次按键都当成一次答题。

指标建议口径
今日完成量分别展示已完成题次、涉及的不同词条数、新词数、复习数。一个词反复重输，不增加不同词条数。
首次无提示正确率本轮首次尝试正确、此前无错误提交且未使用提示的题次 ÷ 已结束题次；跳过进入分母，仍未结束的题次不进入。原始键入中的退格修改不单独算错误提交。
辅助与错误情况显示提示后答对、揭示答案后重输、错误提交次数与高频错词；错误之后最终写对不能回写为首次正确。
有效练习时间只在练习窗有焦点且近期有练习活动时累计；隐藏、失焦和长时间无操作暂停。初始空闲阈值可设为 30 秒，恢复输入时不补计空档。
进度与复习未见 / 学习中 / 待复习 / 达到自设熟练标准分开统计。一次答对只代表本题完成，不直接标记长期掌握。

首版采用可解释的简单队列：到期复习优先，再取选定章节的新词；错词和看过答案的词间隔若干题后重现。跨日间隔可先用可配置的 1、3、7、14 天作为产品起点，失败则缩短间隔；这些数值不是经本次验证的最佳记忆方案。无需为首版引入复杂推荐系统。

数据至少区分词条、学习状态、出题记录与作答事件，保留本地日期 / 时区用于日统计。隐藏不是跳过；崩溃恢复后继续当前题，不把中断算错，也不重复累加已经提交的结果。

6. 实施顺序与验收条件

建议先解决影响体验的桌面行为，再接全量词库。以下是一个熟悉 Windows 桌面开发的开发者的粗略人日估算，不是交付承诺；不包含全书语义级人工审校，也不包含多平台、公开分发签名和内容授权办理。

阶段产物与通过条件估算
① 桌面体验验证用少量样例做 360 DIP 级小窗；验证置顶、拖动锁定、热键显隐、焦点恢复、托盘退出、125% / 150% 缩放。证明日常办公可用。1–2 人日
② 完整拼写闭环稳定词库导入、变体与短语判定、提示、错误重输、自动切题、断点继续；验证前缀变体和中文输入法。2–3 人日
③ 统计与复习本地数据库、明确统计口径、错词 / 到期队列、导出与恢复；验证重复事件与异常退出。2–3 人日
④ 全量验收与打包多屏 / 缩放 / 休眠恢复、快捷键冲突、真实工作软件切换、资源测量、免安装包检查。1–2 人日

功能实现预计约 6–10 人日，词库处理与校对单独估算。755 条未直接匹配的例句应先按规则分组，再抽查约 200 条确认自动处理的可靠性，之后估计剩余人工工作量。功能开发和词库整理可以交错推进，但正式全量版本要对全部 3,674 词条交代去向与处理状态。

首版验收清单

  1. 完整功能：小窗口、固定位置与置顶、全局显隐、中文与遮词例句、提示、正确自动切题、错误重输、统计、复习和重启恢复全部连通。
  2. 词库正确性：全部 3,674 个来源词条可追溯；70 个多形式词条、短语与连字符有针对性用例；4 条空例句补齐；755 条初筛异常全部分类处理，所有训练例句不直接露出目标答案。
  3. 输入边界：未输入完不报错；组合输入期间不切题；前缀变体规则已定稿；快速键入、按键重复、粘贴和多次 Enter 不导致跳过两题或重复记数。粘贴答对单独标注，不进入独立拼写正确率。
  4. 办公体验：工作软件有焦点时小窗不抢输入；隐藏不露出仍打开的统计 / 提示窗口；恢复保留题目与输入；热键冲突后仍可通过托盘操作；多屏拔插后窗口可找回。
