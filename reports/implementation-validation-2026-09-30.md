# 小词窗 1.0 实施与验证记录

日期：2026-09-30。源码目录：`G:\vcrmb`。目标：用户授权实施本地小窗拼写方案，并明确在例句中隐藏待拼写词。

## 已实现

- .NET Framework 4.8 WPF x64 原生程序，无服务器、账号或运行时网络依赖；360 DIP 默认宽度、自动高度、长内容局部滚动、位置记忆、拖动/锁定、置顶、托盘。
- 全局可配置显隐快捷键，窗口内 Esc 隐藏。普通模式不占任务栏按钮；位于任务栏附近，不修改 Explorer 或任务栏。
- 中文释义、遮词例句、正确自动切题、Enter 错误检查、重输、逐级提示、明确看答案、跳过；对允许答案的前缀关系延后自动通过。
- SQLite 本地记录、题目完成事务与幂等、未完成题目恢复、章节切换暂存、到期优先、仅复习、可配置间隔/连续答对目标。
- 日统计、最近 7 天、需要巩固的词、互斥的学习进度分类；辅助输入独立标记，隐藏/失焦/闲置时间不累计。
- 数据库在线备份、结构和词条校验、恢复前备份、原子替换；保留来源 ID 的词库更新。

## 实测环境与构建

- Windows 10 22H2 x64，系统版本 `10.0.19045`；PowerShell 7.6.5。
- 本机 .NET Framework 4.8 系列 Release `533325`，项目按 4.8 参考程序集编译。
- 使用本机 Framework C# 编译器，C# 5，x64，警告视为错误；未全局安装 SDK 或改变系统设置。
- 运行库：System.Data.SQLite 2.0.4 + 官方 SQLite 3.53.4 x64。原生导入名 `e_sqlite3.dll`，内容与官网下载的 `sqlite3.dll` 一致。
- 固定下载 SHA-256 见 `dependencies.json`。发行包附文件清单 `SHA256.json`。

## 全量词库检查

- 3674 个来源词条，22 章，全部保留 ID 和允许答案；3674 条遮词例句，未解决项 0。
- 遮住同一例句内重复出现的词、允许的英美变体、规则/已列明不规则变形。实际判词仍使用来源的允许答案，例句变形不会扩大答案集合。
- 51 个词条有校对记录，其中 40 条使用自拟替代例句，包括原本没有例句的 4 个词。其余涉及释义修正、不规则词形补充。
- 4 个释义原本包含待拼写的英文词，已移除这些英文词头。原释义、原例句仍保存在数据文件中，练习界面不显示它们。
- 全量词库通过原形/登记词形泄漏检查；额外扫描长度至少 4 字母的答案在其他单词中的子串，剩余 0 项。不是对全部语义、语法和教材内容进行过人工审校。

证据：源码 `artifacts/mask-audit.json`、`artifacts/unresolved-masks.json`、`data/corrections.json`。

## 自动化结果：20 项通过，0 项失败

测试使用真实 SQLite 文件和独立的测试数据目录，没有写入正式 `%LOCALAPPDATA%\Vcrmb` 学习记录。

1. 全部 3674 词条的结构、章节和遮词完整性。
2. 英美变体、全角字符、大小写和空白归一化；不误收拼错词或去掉短语空格/连字符的输入。
3. 短答案为长答案前缀时等待确认，长答案可自动通过。
4. 逐级提示，包括单字母边界，不能直接泄露完整答案。
5. 实际加载 SQLite 3.53.4；同一题完成两次只计一次。
6. 输入、错误、提示、看答案和粘贴状态在重开数据库后保留，辅助答对不算独立答对。
7. 切章节保留未完成状态，切回继续，不把暂存算作答错。
8. 仅复习模式排除未完成的新词，返回普通练习后恢复原状态。
9. 自定义复习间隔和目标生效，进度分类不重叠，非法设置不覆盖原值。
10. 事务失败保留原输入和时间。
11. 子进程先提交进度、再开启一个未提交事务，随后被强制结束；重开后保留已提交内容、回滚未提交内容。
12. 队列按到期和章节选词，不提前触发计划复习。
13. 跳过进入正确率分母，不能记成答对。
14. 导出后继续答题，再恢复导出文件，结果与导出时一致，恢复前副本保留。
15. 不兼容词条的备份被拒绝，原学习库保持可用。
16. 备份不能覆盖活动 WAL；伪造版本但缺少结构的备份在替换前被拒绝。
17. 跨日答题结果和学习时间按各自日期保存。
18. 隐藏、失焦、闲置和休眠间隔不累加为学习时长。
19. 词库更新不能把旧 ID 重新指向无关单词。
20. 词库导入拒绝例句中的变形泄漏和释义中的直接答案泄漏。

## 桌面验证的实际边界

本次成功启动过 WPF 程序；Windows 原生控件树可读取中文释义、遮词后的例句、输入框和按钮。首题显示“n. 大气层；氛围”，例句为 “The approaching examination created a tense ______ on the campus”。应用状态确认窗口宽 360 DIP、可见并置顶，运行于 96 DPI。

原拟定快捷键 `Ctrl+Alt+W` 注册时发生占用，程序显示错误而没有崩溃；默认组合已改为 `Ctrl+Alt+Shift+W`。**新的快捷键注册与实际显隐效果尚未做真实按键验证。**

截图接口先后报告 `FrameArrived timed out: timed out waiting on channel` 和 `window capture timed out: timed out waiting on channel`。随后桌面自动化收到实体 Escape 的停止信号，按要求停止了全部界面操作。没有完成真实输入、设置保存、统计页视觉布局、备份对话框或完整快捷键流程。后续改动通过编译与核心测试，但没有再次操作桌面。

- 与工作软件切换时的焦点、全局显隐、托盘、关闭各类子窗口、拖动与锁定。
- 125% / 150% / 200% 缩放、多屏位置记忆、拔插显示器、锁屏/休眠恢复，以及 Windows 11。
- 冷启动 2 秒、热键 100 ms、静置 5 分钟 CPU 和 100 MiB 私有工作集等报告中的性能目标。它们仍是验收目标，本次没有有效完成测量。
